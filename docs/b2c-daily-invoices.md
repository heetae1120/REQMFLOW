# B2C 당일 송장 작업

주문·출고요청에서 위킵 양식을 생성하면 파일 다운로드 여부와 관계없이 출고요청, 생성 파일, 구성품 행과 원래 주문의 직접 연결을 저장합니다. 생성 직후 다운로드는 선택 사항입니다.

실제출고 → 위킵 송장에서 출고요청 기준일을 선택하고 작업 조회를 누르면 저장된 B2C 작업을 모두 선택합니다. 생성한 양식 목록은 기본으로 접습니다. 펼쳐서 대상 작업을 선택할 수 있습니다. B2B와 사입형 B2C는 이번 일괄 화면에 포함하지 않습니다.

위킵 등록일 범위는 출고요청 기준일과 구분합니다. 전체 송장 가져오기는 해당 범위의 B2C 결과를 한 번 조회하여 작업 전체에 대조합니다. 기존 확정 작업을 포함해 주문번호의 판매처 충돌을 검사합니다. 확실한 단일 송장만 자동 확정하며, 복수 송장·정보 불일치·미발급은 검토 또는 대기로 남깁니다. 송장 확정으로 출고 수량이나 ERP 상태를 변경하지 않습니다.

당일 위킵 양식 다운로드 및 송장 포함 통합 양식은 위킵 10열 형식을 유지합니다. 판매처 원본 반영은 생성 당시 보관한 XLSX/XLSM/CSV에 확정 송장을 적용하여 ZIP으로 다운로드합니다. 기존 송장 열을 사용하고 없으면 맨 뒤에 추가합니다. 같은 원본 행에 서로 다른 송장이 연결되면 출력하지 않습니다.

`tracking_sources`는 파일 생성 당시 판매처 원본 스냅샷입니다. 전체 DB 백업과 작업공간 스냅샷 형식 9에 포함됩니다. 과거 작업은 남아 있는 원본의 주문번호·상품행·배송정보가 일치할 때만 연결합니다. 취소된 `request_lines`의 송장 행은 목록과 다운로드에서 제외됩니다. 조회 시작 당시 작업 정보와 달라졌으면 적용하지 않습니다.

기존 별도 송장 작업은 보존합니다. 이미 자동 등록된 출고요청 주문만으로 구성된 중복 입력 작업은 당일 화면에서 숨깁니다. 출고요청 생성 파일이 위킵 10열 양식인 경우만 자동 등록합니다.
