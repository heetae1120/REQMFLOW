# 폐쇄몰 자동 로그인 — 1단계

FLOW 왼쪽 `주문 수집`에서 계정을 등록하고 판매처를 선택하여 실행한다. 판매처는 19곳이다. 주문 수집과 엑셀 다운로드는 다음 단계다.

## 계정 등록과 수정

`계정 관리` 버튼 또는 판매처 행 더블클릭으로 계정 설정 창을 연다. 판매처와 REQM·ORORA 인증 메일을 선택하고 아이디·새 비밀번호를 입력하여 `계정 저장`을 누른다. 이지웰은 거래처 코드도 입력한다. 계정 등록에 엑셀은 필수가 아니며 일괄 등록이 필요할 때만 사용한다.

기존 비밀번호는 설정 창에도 표시하지 않는다. 등록된 계정의 비밀번호 입력란을 비우면 기존 비밀번호를 유지한다. 새 비밀번호는 기본적으로 가리며 필요시 `새 비밀번호 보기`로 확인한다. 변경은 다음 로그인부터 적용되므로 실행 중이거나 브라우저 세션이 열려 있으면 먼저 종료한다.

계정은 현재 PC의 Windows 사용자에게 암호화하여 저장한다. 별도 FLOW 마스터 비밀번호나 공유 계정 저장은 이번 변경에 포함하지 않는다. 다른 Windows 사용자에게 자동 공유되지 않는다. 엑셀을 다시 불러올 때 포함된 계정은 갱신하되, 엑셀에 없는 기존 계정은 유지한다.

| 인증 수단 | 판매처 |
|---|---|
| REQM 이메일 | 무신사, 29CM, 베네피아, 크림 |
| ORORA 이메일 | 현대이지웰, 오늘의집, 현대홈쇼핑(필요시) |
| REQM CS SMS | SSF SHOP, W컨셉, 핫트랙스 |
| 작업자 인증번호 | 이알아이, 삼성카드복지몰, 한섬 |
| 일반 로그인 / 기존 세션 | 이제너두 ETBS, 컬리, 삼몰, shop by, 에이블리, 지그재그 |

## 실행과 연결

백그라운드 실행은 전용 Chrome 프로필을 사용한다. SMS 자동 수신은 `인증 수신 연결`에서 Google 메시지를 REQM CS 계정(reqm.cs@gmail.com, 전화번호 끝자리 2054)으로 처음 연결해야 한다. 연결 후 `브라우저 세션 닫기`를 누르고 로그인을 실행한다.

메일 계정도 엑셀에서 불러온다. REQM·ORORA 웹메일에 로그인하여 전체 메일함에서 판매처별 인증 메일을 검색한다. 발송 전에 기존 메시지 ID를 기록하고 새로 도착한 인증 메일만 읽는다. SMS는 등록 발신번호의 직전 인증번호와 비교한다. 자동 수신을 확인하지 못하면 FLOW 인증번호 입력창으로 전환한다.

이알아이·삼성카드복지몰·한섬은 계정을 자동 입력하고 작업자가 FLOW 입력창에 새 인증번호를 입력한다. 선행 0을 포함한 6자리·취소·만료를 처리한다. 이 세 곳의 실제 휴대전화 인증은 사용자 요청으로 나중에 검증한다.

무신사·29CM은 통합 로그인 주소를 각각 사용하고 순차 실행한다. 이지웰은 이메일 인증 후 `유저정보 → 복지샵(10064255) → 선택`을 실행한다. shop by는 기존 작업자의 로그인을 유지한다.

## 저장과 결과

엑셀 URL은 계정 분류에 사용하고 실제 탐색은 등록된 주소만 사용한다. 계정은 `%LOCALAPPDATA%/REQMFLOW/closed-malls/accounts.dat`에 Windows DPAPI로 암호화한다. 브라우저 프로필과 결과도 로컬에 보관하고 공유 주문 DB에 전송하지 않는다. 인증번호와 비밀번호는 결과에 저장하지 않는다.

판매처·성공/실패/중단·사유·시간·로그인 방식을 기록한다. 업무 화면을 확인한 경우만 성공으로 표시한다. 성공 세션은 다음 단계에 활용하도록 유지하므로 재실행 전에 `브라우저 세션 닫기`를 누른다. `중단`은 대기를 취소한다. 실패해도 다음 판매처로 진행하며 인증번호를 무한 재시도하지 않는다.

## 검증 상태와 1.9.16 배포 범위

2026-10-07 FLOW 엔진의 백그라운드 로그인 성공을 확인한 판매처는 에이블리, 지그재그, 현대홈쇼핑, 삼몰, 컬리, shop by, 이제너두 ETBS, 베네피아, 무신사, 29CM, 오늘의집, 현대이지웰이다. 이메일 인증 다섯 곳은 자동 수신과 인증까지 확인했고 이지웰은 복지샵 전환도 확인했다.

크림은 `백그라운드 실행`을 해제하면 REQM 이메일 인증까지 자동으로 완료했다. 같은 프로필의 헤드리스 실행에서는 로그인 API의 OPTIONS 요청이 HTTP 500을 반환하여 OTP 화면에 진입하지 못했다. 서버 정책인지 브라우저 호환성인지 원인은 확정하지 않았다. 창 최소화 및 자동 실행 방식 전환은 아직 구현하지 않았다.

W컨셉은 FLOW의 백그라운드 실행에서 별도 SMS 인증 팝업과 업무 화면 진입을 확인했다. 해당 테스트는 기존 Chrome의 REQM CS 문자를 테스트 콜백으로 전달했으므로 FLOW 전용 Google 메시지의 자동 수신 검증을 의미하지 않는다. SSF·핫트랙스는 인증 입력 단계까지 확인했다. 세 판매처의 자동 SMS 완료는 전용 Google 메시지를 연결한 뒤 추가 검증해야 한다. W컨셉의 직전 테스트에서 업무 화면이 열렸어도 오류 결과가 기록된 적이 있어 결과 판정 안정성도 후속 검증 대상이다.

이알아이·삼성카드복지몰·한섬의 실제 휴대전화 인증은 사용자 요청으로 보류했다. 프로그램의 작업자 인증번호 입력창은 테스트로 검증했다.

로그인 회귀 테스트는 계정 분류·암호화·새 인증 메시지 판별·입력창·취소·만료·선행 0·인증 순서·SSO 이메일 선택·크림 자동 제출·W컨셉 팝업 종료를 다룬다. 브라우저 회귀 테스트는 합성 로컬 페이지를 사용한다. 과거 관찰 기록과 실제 엔진 검증 기록은 별도 보존한다.

1.9.16은 폐쇄몰 자동 로그인 메뉴를 배포한다. 29CM 주문 상태 변경 및 출고 엑셀 다운로드는 별도 테스트로 확인했으며 이번 버전의 주문 수집 메뉴에 통합하지 않았다. 다운로드 전용 저장 폴더와 예약 실행은 사용자의 2026-10-08 요청에 따라 작업 및 배포 범위에서 제외한다.
