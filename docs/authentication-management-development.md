# 인증 관리 로컬 개발 — 2026-10-08

주문 수집 화면에서 사용하므로 사용자의 후속 요청에 따라 1.9.19 배포에 함께 포함한다. SMS 실환경 검증은 별도 미완료 상태다.

- 메인 화면의 인증 수신 연결 버튼을 제거하고 계정 관리에 인증 수신처와 공통 SMS 설정을 추가했다.
- 판매처별 인증 메일(REQM / ORORA) 선택, 자동 수신 시도 또는 작업자 입력을 저장한다. 수신처 변경은 사이트에 등록된 이메일을 변경하는 기능이 아니다.
- REQM·ORORA 메일 비밀번호는 기존 Windows 암호화 계정 저장소에서 관리한다. 인증 설정 파일에는 비밀번호·인증번호를 저장하지 않는다.
- SMS 자동 수신은 기본적으로 꺼져 있다. Google 계정과 휴대전화 끝자리 정보를 입력하고 인증 설정 저장을 눌러 활성화한다. 전화번호 정보는 작업자가 확인하는 안내 정보이며 실제 연결된 전화번호를 자동 검증하지 않는다.
- 이알아이·삼성카드복지몰·한섬은 작업자 입력을 유지한다. 자동 수신을 끄거나 수신에 실패하면 FLOW 인증번호 입력창으로 진행한다.
- FLOW 브라우저 세션이 있고 로그인 작업이 진행 중이지 않을 때 20초마다 연결을 확인한다. 로그인 작업 중에는 SMS 읽기 이벤트로 상태를 갱신하며 동시 브라우저 명령을 보내지 않는다. 확인 시각을 표시한다.
- 계정 관리의 연결 상태 확인은 즉시 상태 확인을 요청한다. 브라우저 세션이 없으면 확인 불가로 표시한다. 메시지 목록 접근과 이번 요청의 새 인증번호 읽기를 구분하며 접근만으로 수신 검증 완료를 표시하지 않는다.
- 일반 브라우저에서 Google 메시지를 여는 버튼을 제공한다. 일반 Chrome의 로그인 세션과 FLOW의 세션은 별개다. 일반 Chrome에서 FLOW로 문자를 읽는 연결 및 Google 로그인 차단 해결은 아직 미검증이다. 개인 브라우저 쿠키를 복사하거나 보안 설정을 해제하지 않는다.

검증은 설정 저장, 수신처 라우팅, 기본 비활성화, 수동 인증 유지, 잘못된 설정 보호, 계정 오연결·전화 연결 끊김·검증 전 표시, 계정 관리 UI 및 로컬 합성 사이트의 로그인 회귀 테스트로 수행한다. 실환경 SMS 수신 검증을 완료한 것으로 간주하지 않는다.
