# 주문 수집 화면 로컬 개발 — 2026-10-08

- 메뉴·제목을 폐쇄몰 로그인에서 주문 수집으로 변경했다.
- 판매처 / 로그인 / 수집 대상 주문 / 엑셀 다운로드 / 진행 상태·결과의 다섯 열로 표시한다.
- 선택 판매처, 완료, 진행 중, 인증 대기, 실패, 후속 작업 대기, 중단과 확인된 주문 합계를 표시한다. 미조회 판매처 수를 함께 보여준다.
- 로그인 성공만으로 전체 완료를 표시하지 않는다. 아직 연결되지 않은 주문 조회·다운로드 단계는 미구현으로 표시한다. 실주문 수를 확인하지 않은 상태는 `—`이며 `0건`으로 추정하지 않는다.
- 행 선택 시 계정 등록·인증 방식·상세 사유·로그인 처리 시간을 표시한다. 더블클릭하면 계정 관리가 열린다. 상태는 글자와 행 색상을 함께 사용한다.
- 새 실행은 선택한 판매처의 이전 상태를 초기화한다. 다른 판매처 기록은 유지하며 판매처별 로그인 결과를 즉시 갱신한다.

이번 변경은 화면 및 상태 모델 개발이다. 판매처별 실주문 조회·엑셀 다운로드, 파일 검증·파일 열기, 실패 단계 재시도는 아직 통합하지 않았다. 이전 29CM 단독 테스트를 전체 수집 기능 완료로 취급하지 않는다. 다운로드 전용 저장 폴더·예약 기능도 구현하지 않았다. 사용자의 후속 요청으로 1.9.19 커밋·푸시·업데이트 배포 범위에 포함한다.
